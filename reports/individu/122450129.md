# Laporan Perorangan — Vira Putri Maharani (122450129), Jalur CNN

## 1. Komponen Saya
Saya mengembangkan arsitektur 1D Temporal Convolutional Neural Network (1D-CNN) untuk menghitung repetisi latihan peregangan meja kerja dari runtun waktu koordinat sudut sendi (10 fps, 190 langkah waktu setelah trimming). Peran model ini dalam komparasi tim adalah sebagai representasi arsitektur berbasis konvolusi temporal yang mengeksplorasi efisiensi komputasi, parameter rendah, dan latensi ultra-cepat untuk deployment di laptop meja.

## 2. Keputusan Desain
Keputusan desain utama adalah memanfaatkan konvolusi 1D dengan kernel temporal berukuran 5 dan Global Average Pooling, daripada meratakan seluruh dimensi waktu (Flatten) atau menggunakan fully connected besar. Alternatif flatten ditolak karena menyebabkan ledakan parameter model (> 500 KB) dan rentan terhadap overfitting variasi durasi istirahat antar-repetisi.

## 3. Kegagalan dan Pelajaran
Pada eksperimen awal tanpa trimming 1 detik pertama, konvolusi menangkap noise inisiasi posisi duduk partisipan yang belum stabil sehingga galat estimasi repetisi melonjak. Setelah menerapkan pembuangan 10 frame pertama sesuai protokol tim, estimasi MAE menurun secara signifikan.

## 4. Hasil
Hasil evaluasi awal menunjukkan model 1D-CNN mampu mengekstraksi osilasi repetisi dengan baik.

## 5. Yang Akan Saya Ubah Jika Ada Satu Sprint Lagi
Saya akan menambahkan mekanisme Dilated Convolution bertingkat untuk memperlebar receptive field temporal tanpa menambah jumlah parameter, serta mengonversi model ke format INT8 ONNX terkuantisasi untuk menguji batas latensi minimum pada prosesor laptop meja kerja.
